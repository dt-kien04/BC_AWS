**On this page**, you will find an overview of my worklog during the First Cloud AI Journey (FCAJ) internship program.

The worklog documents the activities, knowledge, and practical experience gained throughout the internship. It covers a period of 10 weeks, focusing on AWS cloud fundamentals, infrastructure deployment, and security implementation.

During these weeks, I studied AWS core services, designed and deployed an AWS network architecture, configured compute and database resources, and implemented security and monitoring services. I also performed basic connectivity and security tests to evaluate the deployed infrastructure.

The main activities completed during the internship are summarized below:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Topic Survey and Familiarization with the AWS Platform](1.2-week2/)

**Week 3:** [Application Source Code Analysis and Version Control with GitHub](1.3-week3/)

**Week 4:** [Designing and Deploying the Virtual Private Cloud (Amazon VPC)](1.4-week4/)

**Week 5:** [Establishing Network Security Layers (Security Groups)](1.5-week5/)

**Week 6:** [Deploying the Managed Database Service (Amazon RDS)](1.6-week6/)

**Week 7:** [Launching the Web Server (Amazon EC2) and Remote Administration](1.7-week7/)

**Week 8:** [Configuring the Web Server Environment and Deploying Web Travel](1.8-week8/)

**Week 9:** [Packaging Server Templates (AMI) and Configuring Auto Scaling](1.9-week9/)

**Week 10:** [Operational Troubleshooting, Database Verification, and Cost Optimization](1.10-week10/)

**Week 11:** [Result Consolidation, Thesis Report Writing, and Defense Preparation](1.11-week11/)
