### 1. Introduction

Problem Context: The Web Travel application provides tour browsing, user account registration, tour booking, and administrative management features. Deploying on AWS enables 24/7 operational stability while completely decoupling the presentation server from the data storage layer.

Target Architecture: Deployed in the Singapore Region (ap-southeast-1) across two Availability Zones (ap-southeast-1a and ap-southeast-1b), optimized to operate well within a 100 USD AWS Promotional Credits budget.
